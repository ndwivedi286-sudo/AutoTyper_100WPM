# Auto Typer 100 WPM — Windows

## 1. Install Python
Install Python 3.10+ and make sure "Add Python to PATH" is checked.

## 2. Install dependencies
Open Command Prompt in this folder:

    pip install -r requirements.txt

## 3. Run
    python main.py

## 4. Use
1. Paste your text into the Auto Typer window.
2. Select your WPM (100 is default).
3. Open Notepad, Word, browser text box, WhatsApp Desktop, etc.
4. Put the cursor exactly where you want the text.
5. Press F8.
6. You have 2 seconds to switch/focus the target app.
7. F9 pauses/resumes.
8. F10 stops.

## Safety
Do not use this to bypass CAPTCHA, anti-bot systems, rate limits, or other access controls.
